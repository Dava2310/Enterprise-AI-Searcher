# Enterprise AI Searcher

> 🚧 **Work in progress** — currently on Week 0 (project setup).

An enterprise search engine powered by AI. It connects to sources such as Google Drive, Notion, Slack and GitHub, indexes their content, and answers questions with citations while respecting what each user is allowed to see.

This is a public project built for educational purposes, to learn and showcase skills in: Python backend development, RAG, embeddings, permissions, and agents.
